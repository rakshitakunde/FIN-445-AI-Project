      About this tool
      
    
      
      
      Business application
      Most business people work with data exports such as sales reports, survey results, HR records or campaign results, but answering a question usually means waiting for an analyst or wrestling with Excel. Ask Your Data lets anyone load a dataset and get answers, statistics and charts in seconds. That speeds up decisions and reduces the load on analytics teams.
      
      
      How it works
        
        
      • Automatic profiling: detects each column's type (number, date, text), handles missing values, and computes summary statistics.
        • 
        
      • Natural-language query engine: matches your words to columns and values, detects the analysis type (aggregate, group, trend, correlation, distribution, share) and generates SQL.
        • 
        
      • Statistics: Pearson correlation, linear regression, quartiles, IQR outlier detection, skew.
        • 
      
      
      
      Limitations
      The query engine is rule-based and runs entirely in the browser, so it needs no API key, login or server. As a result it understands analysis questions about the loaded data, not open-ended conversation. A link loads only if its host allows it; otherwise download the file and upload it. Large files are streamed in chunks; up to 5 million rows are loaded.
